## 这是什么

一套视频号直播复盘的方法与工具，解决一个问题：**一场直播下来，怎么知道哪个环节拖了后腿。**

产出四样东西：

1. **数据层**：整场与分时段的核心指标（观看、停留、互动、成交、GPM）
2. **时间轴**：把讲解过品的时间点对上分钟级成交曲线
3. **录屏**：直播回看下载，可复看具体话术
4. **结论**：哪几分钟是有效讲解、哪里在空转、下次该改什么

## 为什么不能只看后台大屏

后台大屏给你的是**整场汇总**。但一场两小时直播，问题往往只在其中二十分钟。

「这场 GPM 低」是结论，不是诊断。要知道为什么低，必须把**讲解动作**和**成交曲线**按时间对齐，看哪次讲解没转化成单。

## 核心方法

### 1. 抓数据

登录视频号助手，取数据大屏的分时数据。

### 2. 下载录屏

直播回看的 m3u8 流，下载后做音轨分析。

### 3. 对齐时间轴

把「几点几分讲了哪个品」和「几点几分出了多少单」放在同一条时间线上。

### 4. 识别憋单

憋单的特征：长时间不给价、反复强调卖点、互动量上升但成交延迟释放。时间轴上表现为「互动峰值先到、成交峰值后到」。

### 5. 出结论

每场给出三条：哪段最有效、哪段空转、下一场改哪一处。
